Rules for this rating (from the paper's method)
  • Defect: one mechanism in the Rust that makes it return a wrong result or crash on an input where the C is well-defined. The C is the oracle.
  • Not counted if the divergence occurs only: (i) where the C has undefined behavior; (ii) on inputs that break a precondition the original states in its name, comments or documentation; (iii) in a value the C standard leaves unspecified; (iv) in a callback that frees memory; (v) when a negative value is passed to scanf %u or printf %x/%u. Hangs and build failures are not defects.
  • Class (counted only): outright, wrong on ordinary, well-formed input; edge, differs only on malformed or extreme inputs where the C is defined; C bug not copied, the Rust fixes a C bug or follows a recorded expected output instead of the C; other.
